name: m-cycle
series: common
summary: 循環の図。段階の箱を円の上に 12 時から時計回りに並べ、円に沿った矢印でつなぐ（最後から最初へ戻る矢印も）
steps: 段階の数（既定は 1 つ = 1 段階。per-step で n 個ずつ、node の step が優先）
purposes: cycle
variants: fade, draw, grow
props: per-step, size, dur, stagger

PDCA、水の循環、細胞周期、学習のサイクルなど、同じ順で回り続ける段階を見せるときに使う。
座標は書かない。段階の中身を配列の順に書けば、部品が並べる（[共通の決まり](../../docs/conventions.ja.md) §2）。

子の JSON：`{"nodes": [...], "center": {...}, "edges": [...]}`（`center` と `edges` は省ける）。

- `nodes`：段階（3〜8 個を想定）。配列の順に回る。12 時の位置から時計回りに置き、となりの段階へ円に沿った矢印を引く。最後から最初へ戻る矢印は自動で引く
  - `label`（`\n` で改行）か `tex`（KaTeX）、`note`（箱の中の 2 行目に小さく、`--muted`）、`tone`（`term`（既定）・`emph`・`muted`・`accent2`・`series-1..4`）、`step`、`at`、`id`
- `center`：真ん中の名前（`{"label": "PDCA", "note": "…"}`）。最初の段階と一緒に出る（`center.step` で変えられる）
- `edges`：ほかのつながり（`from` `to` は段階の `id`、`label` `tone` `dash` `step`）。箱の縁から縁への破線の矢印

並べ方：

- 横に長い場所では円を横に伸ばした楕円にする（縦の 1.9 倍まで。縦に長くはしない）。箱と矢印が要素の箱に入る大きさにする
- 段階：既定は 1 段階に 1 つ。入ってくる矢印はその段階の箱と一緒に出る。最後から最初へ戻る矢印は、最後の段階の箱が出たあとに引く
- 見せ方（`variant`）：`fade`（既定。箱が現れてから入ってくる矢印を引く）・`draw`（矢印を先に引き、その先に箱が出る）・`grow`（矢印を引き、箱が矢印の先から伸びて出る）。書かなければ資料のシード値（`data-egatari-seed`）で選ばれる。どれも段階の数・長さ・最後の形は同じ
- 授業の表示（`?mode=lecture`）：後の段階の箱と矢印を薄く（0.45）見せる
- `cues(k)`：同じ段階に 2 つ以上の箱があれば、2 つ目からの開始時刻を返す

見本は `demo.html`（PDCA、水の循環、見せ方の種類）。

注意

- 箱の幅は字数から見積もる（和文 1 字、数字 0.6 字、ほかの欧文 0.62 字）。字の読み込みを待たずに決まる
- 入らないとき（箱どうしが重なる・矢印を引く間がない・真ん中の名前が円に入らない）は字を `size` から 2px ずつ 24px まで縮め、それでも入らなければ `console.warn` で知らせる
- 矢印は楕円の弧（SVG の `A`）で、箱から 8px 空けたところから次の箱の手前まで。段階が 8 個を超えると矢印が短くなりすぎる
