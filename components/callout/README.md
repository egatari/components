研修の操作の説明、窓口や病院の職員向けの手引き、アプリの使い方など、画面のどこをどの順に操作するかを 1 つずつ見せるときに使う。

画像は子の `<img src="screens/apply.png" alt="…" width="1280" height="800">`（作業フォルダの画像。組み立てが教材に埋め込む）。

- **画面の画像に本当の個人の情報を写さない**（名前・番号・住民や患者の記録など）。架空のデータで画面を作るか、ぼかしてから使う
- `alt`（何の画面か）は必ず書く。ない、または空なら品質チェックが data で知らせる
- `width` と `height` は画像の大きさ（px）。丸の位置の計算に使う。ないと data で知らせ、16:10 として描く
- 埋め込んだ画像が 1 MiB より大きいと、品質チェックが size で知らせる（大事な所だけ切り抜くか、幅 1600 px くらいの JPEG・WebP にする）

子の JSON：`{"callouts": [...]}`。

- callout：`x`・`y`（丸の位置。画像の幅と高さに対する割合 0〜1）、`text`（説明。`\n` で改行）、`box`（`[x, y, 幅, 高さ]`、同じ割合。そのステップの間だけ操作する所を `--emph` の枠で囲む）、`step`、`at`
- 説明は画像の横（`side`：`right`（既定）・`left`・`both`）に、丸の上下の順に並ぶ。重なれば下へずらし、引き出し線どうしは交わらない
<!-- llm: omit -->
- ステップごとに、丸（今のステップは `--emph`、前のステップは `--term`）、引き出し線（`--fg`）、説明の順に出る。説明には丸と同じ番号が付く
- 引き出し線は丸から画像の端の外まで水平に、そこから説明まで斜めに引く。説明の並びが丸の上下の順と同じなので、線どうしは交わらない
- 説明が列の幅（`label-width`、要素の幅に対する割合）に入らない、または列の高さに入らないときは size で知らせる
- 先のステップを薄く見せる表示（`ctx.preview`）：先の丸・線・説明を `--preview-opacity` の濃さに
<!-- llm: end -->

サンプルは `demo.html`（架空の市の電子申請の画面で、住所変更の届け出の 5 つの手順。説明を両側に置く例）。

注意

- 1 枚に 6 つくらいまで。手順が多ければ画面を分ける
- 丸が操作する所を隠さず、引き出し線がその上を通らないよう、x・y はボタンや欄の、説明の側の端に置く（side="right" なら右の端）
