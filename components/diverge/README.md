前年の利益から今年の利益までの増減の内訳、予算と実績の差の要因、人口の増減（生まれた・亡くなった・転入・転出）など、
基準から合計までに何がどれだけ足され、引かれたかを 1 つずつ見せるときに使う。高さ 400px 以上を目安に置く。

子の JSON：`{"items": [...]}`。

- item：`label`（`\n` で 2 行）、`value`、`total`（`true` なら合計の棒）、`tone`（`emph` などテーマの変数の名前。棒と値の数字の色）、`step`（既定は per-step から）、`at`（ステップの中の開始秒）
- 合計の棒（`"total": true`）は 0 から伸びる。最初の棒が合計の棒なら、その `value` が基準になる
- 増減の棒は、前の棒の端（それまでの累計）から `value` の分だけ上（正）か下（負）へ伸びる
- 値の軸は既定で 0 から。人口のように大きな値の小さな増減は `min="50000"` のように軸の始まりを決める（棒の端と合計がすべてそれ以上のとき。基線の左の端に切れ目の印（斜めの 2 本）が付き、合計の棒は軸の下の端から伸びる）
- 後の合計の棒は累計から高さを決める。`value` を書いたときは累計と合うかを確かめ、合わなければ品質チェックが data で知らせる（棒は累計で描く）
<!-- llm: omit -->
- 色：合計 `--term`、増加 `--accent2`、減少 `--emph`。値の数字は棒の上の端の上に書き、増減には `+` か `−` を付ける（色だけで向きを伝えない）。棒がすべて 0 より下にあるときだけ、下の端の下に書く
- 隣の棒の間を、前の棒の終わりの高さで点線（`--muted`）でつなぐ（`links="false"` で消す）。点線は後の棒と同時に出る
- 値の軸は 0 と、すべての棒の端を含む。0 の基線は `--fg`。値の数字は `digits` 桁で 3 桁ごとにカンマを入れ、`unit` を後ろに付ける
- 先のステップを薄く見せる表示（`ctx.preview`）：先のステップの棒・値・点線を、伸びきった形で `--preview-opacity` の濃さに
<!-- llm: end -->

サンプルは `demo.html`（前年の利益から今年の利益まで、町の人口の増減、途中の小計）。数値はすべて架空。

注意

- 棒が多いと名前が詰まる。10 本くらいまでにし、名前は短く（2 行まで）する
- 増加と減少の色は良し悪しを表さない（費用の減少も `--emph`）。良し悪しを示したい棒は `tone` で色を変える
