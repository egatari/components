name: m-kakijun
series: kokugo
summary: かな（ひらがな・カタカナ）の書き順。字を 1 画ずつ、書く順と向きのとおりに書いて見せる
steps: 字 1 つ＝1 段階（段階の中で 1 画ずつ）。per="stroke" なら 1 画＝1 段階
purposes: process
variants: draw, pen
props: text, per, writing, grid, ghost, nums, ends, size, dur
---

`<m-kakijun text="あさ" style="height:320px"></m-kakijun>`。ひらがな・カタカナ、濁音・半濁音、小さい字（ゃ・っ など）、ー を書ける。

- 枠と十字の補助線の中に書く（`grid="none"` で消す）。まだ書いていない画は薄く（`ghost="off"` で見せない）
- 書き始めに丸い番号（`nums="off"` で消す）。`ends="on"`：画の終わりに とめ・はね・はらい
- `writing="tate"`：縦書き（上から下）。小さい字はます目の右上、横書きでは左下
- データにない字（漢字・記号）は書き順なしでそのまま出す

作る人向けの注

- **字の形はフォント、順と向きは独自のデータ**：字のフォントは「Egatari Kana, derived from Klee One, SIL OFL 1.1」（かな 166 字の部分集合で、名前を変えたもの。字の形は変えていない）。それを SVG の字で描き、`index.js` に base64 の woff2 として入れてある（約 40 KB。`@font-face` の family は "Egatari Kana"）。ライセンスはこのフォルダの `OFL.txt` と、リポジトリの `NOTICE`。筆順データ（中心線・終わり・小さい字の位置）は独自に作ったもの（MIT、`data/kana/README.md`）で、フォントの輪郭は使っていない
- **データの写し**：`index.js` の BEGIN/END kakijun-data は `node tools/kana-embed.mjs` が `data/kana/kana.json` から書く（d・end・place・count だけ。手で直さない）。kakijun-font も同じ道具が書き、`--check` が sha256 を確かめる
- **見せ方の仕組み**（`data/kana/proto.html` と同じ）：フォントの字を、中心線で作ったマスクで見せる。マスクは 3 層：書いた部分の太い筆（13）、まだ書いていない部分の黒いガード、書いた部分の細い筆（字の 0〜100 の座標）。ガードと細い筆の幅は、データの画の `w`（画を長さで 3 つに分けた所ごとの、測ったインクの幅）に 1.75 と 1.25 を足したもので、3 分の 1 ごとに同じ path を破線で描く（`w` がなければ 12 と 9）。最後の画のあとはガードがなく、字がすべて見える（`tools/test-kakijun.mjs` が全 166 字で 99 % 以上を確かめる）。2 つの画が交わる所のインクは、先に少し見えることがある
- **小さい字**：データの `place.yoko`（左下の 4 分の 1）か `place.tate`（右上の 4 分の 1）の行列で、字とマスクを同じに動かす。縦書きの ー はデータがないので横書きの形（`console.warn`）
- **大きさ**：字の枠は既定で要素に合わせて 200〜300 px。1 行に入らなければ折り返し（縦書きは右から左へ列を足す）、それでも入らなければ小さくして `console.warn`。`size` で決められる。番号は 24 px の字の丸、終わりの言葉も 24 px で、互いに重ならない所を探して置く（tools/kana-sheet.mjs と同じく、書き始めの手前から回して探す）
- **時間**：1 画は `dur`（0.6 秒）を長さで 0.6〜2.2 倍、画の間は 0.15 秒。`cues` は画の書き始め
- 見せ方：`draw`（0）は筆で書いていく。`pen` は筆の先に小さな点が付いて進む（画を書き終えると消える）。フェードの見せ方はない：書く向きと順がこの部品の中身で、フェードではそれが見えなくなる。授業の表示（`ctx.preview`）では、後の段階の字をテーマの `--preview-opacity`（なければ 0.45）で薄く見せる（いまの段階はふつうに描く。`per="stroke"` では字ごとに薄く重ねるので、いまの画の書いていない部分も薄く見える）
- 読める層：字ごとに画数と、画ごとの とめ・はね・はらい を、画面に出ない段落（`.sr-only`）に置く
