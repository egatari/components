年ごとの売上・費用、聞き取りの結果の順位、導入の前と後の比較など、量を 1 つずつ見せて比べるときに使う
（motion-slides スキル §6「量を比べる」）。

子の JSON：`{"series": [...], "groups": [...], "scale": [...], "sig": [...]}`。

- group：`label`（`\n` で 2 行）、`value`（系列が 1 つ）か `values`（系列の数だけ）、`err`（誤差棒。下を見る）、`step`（既定は per-step から）、`at`（ステップの中の開始秒。既定は同じステップの中で stagger ずつずらす）、`tone`（`emph` などテーマの変数の名前。その組の棒をすべてその色にし、値の数字も同じ色にする）
- series：`label`（系列が 2 つ以上のとき、最初の組の棒に直接書く。縦棒は棒の上、横棒は値の数字の右（負の棒は下・左）。凡例は作らない）、`tone`（既定は `--series-1..4` の順。系列が 1 つなら `--term`）
- scale：`[{"step": 3, "max": 27, "at": 0.4}]`。そのステップの at 秒から zoom 秒かけて、値の軸の上限を max へ動かす（対数で補間）。動く間は前の上限までの範囲を薄い帯で残し、目盛りは前の組と次の組を入れ替える。上限を超える棒は軸の上端で止まり、上限が広がるにつれて伸びる
- 誤差棒（`err`）：数なら ± その値、`[下, 上]` なら区間の端そのもの（信頼区間など）。`values` の組では系列ごとの並び（`[0.2, [3, 5]]`。数 1 つなら全部の系列に同じ ±）。棒（点）が伸びきってから、値の数字と一緒に出る。値の数字は誤差棒の端の外に書く。何の区間か（標準偏差・標準誤差・95 % 信頼区間）は見出しか脚注に書く
- `mark="dot"`：棒の代わりに値の位置に点を描く（平均と誤差棒を、0 から伸びる棒にせずに見せる）。点は伸びずに現れる
- 有意差の括弧（`sig`）：`[{"from": 0, "to": 2, "label": "**"}]` は組 0 と組 2 の棒を括弧でつなぎ、上に印（既定は `*`）を書く。`"group": 1` を書くと、その組の中の系列 `from` と `to` をつなぐ。間の棒の値の数字より上に置き、横に重なる括弧は短いものから順に上へ重ねる。既定はつなぐ組の後のほうのステップで、値が出てから出る（`step` で変えられる）。縦棒の、積み上げでない棒だけ
<!-- llm: omit -->
- 軸の上限は `max` か JSON の `max`、なければ値（scale があれば、最初の scale より前に出る組の値）の 1.12 倍を切りのよい数にしたもの
<!-- llm: end -->
- 横棒（`orient="h"`）は組の名前を左に、値を棒の右に書く。順位を見せるなら `ticks="false"` で目盛りを消してよい
- 積み上げ棒（`stack="true"`、`"percent"` なら各組 100 %）：組の `values` を横に並べず 1 本に積み上げる（全体と内訳を組ごとに見せるとき）。下の系列から順に色が満ちながら棒が合計まで伸び、合計を棒の端に（`unit` 付き）、それぞれの値を区切りの中に単位なしで書く（区切りが字より小さければ書かない）。系列の名前は、縦棒なら最後の組の棒の右、横棒なら最初の組の棒の上に、区切りの真ん中にそろえて書く。軸の上限は合計から決める。組の `tone` は合計の数字の色になる（区切りの色は系列の色のまま）。値は 0 以上にする（負の値は 0 として描く）
<!-- llm: omit -->
- 値の数字は `digits` 桁で 3 桁ごとにカンマを入れ、`unit` を後ろに付ける
- 負の値（積み上げでない棒）：値の軸に 0 を含め、0 の基線（`--fg`）から下（横棒は左）へ棒を伸ばす。目盛りは 0 の両側に同じ間隔で、0 の目盛りの字は基線に付く。0 より下の範囲は、いちばん下の棒の端の外に値の数字が入るように決める（縦棒は 40 px、横棒は数字の幅 + 24 px をあけてから切りのよい数に）。値の数字は棒の端の外側：正なら上（横棒は右）、負なら下（横棒は左）。系列の名前も負の棒では下（左）。値がすべて 0 以上なら、これまでと同じ描き方。`scale`（上限を動かす）と一緒に使うと、上限が動くにつれて 0 の位置も動く
- 100 % の積み上げ棒（`stack="percent"`）：組ごとに値を合計で割って 100 % にそろえる。軸は 0〜100 %（目盛りにも % を付ける。`max` と `scale` は使わない）、区切りの中の値は `digits` 桁の %（字の箱が区切りの中に四方 6 px 以上の余白をもって入らなければ書かない。ふつうの積み上げ棒の決まりは v1.11.0 のまま）。端の合計はどの棒も 100 % なので書かない。負の値は 0 として描き、合計が 0 の組は棒を描かない
- 先のステップを薄く見せる表示（`ctx.preview`）：先のステップの棒・値・合計・系列の名前を、伸びきった形で `--preview-opacity` の濃さに。軸の上限の変化（scale）は先に見せない（今のステップは今の上限のまま）。今の上限に収まらない棒は先に見せない（上限で切ると値を読み違える）
<!-- llm: end -->

サンプルは `demo.html`（年ごとの売上と軸の広がり、聞き取りの順位、2 系列、売上の内訳の積み上げ、前年比の増減（負の値）と答えの割合（100 % の積み上げ）、平均点の誤差棒と有意差の括弧、点と誤差棒）。数値はすべて架空。

注意

- 値の数字は既定で棒が伸びきってから出す。伸びる途中の値は読めてしまうと「データ」に見えるため。数え上げたいときだけ `count="true"`。積み上げ棒で `count="true"` にすると数え上げるのは端の合計だけで、区切りの値と系列の名前は伸びきってから出る（ステップの長さはその分 0.35 秒長い）
- 系列の名前は最初の組の棒に書くので、組の棒が細いと隣の系列の名前と重なる。系列は 2〜3 つまでにする
