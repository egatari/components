中学の作図（垂直二等分線・角の二等分線・垂線）と、図形の性質（円周角・三角形の内角の和）を見せるときに使う。証明の文は書かない（証明は本文か m-flow で）。高さ 440px を目安に置き、説明の欄は図の右（狭い要素や縦書きのスライドでは図の下）。

座標は論理の座標（x は右、y は上）で、図の大きさに合わせて自動で縮める。**交点の座標は書かない**：`meet` で 2 つの線・円の交点をパーツが計算する。

```json
{"points": {"A": [-3, 0], "B": [3, 0]}, "ops": [
  {"seg": ["A", "B"]},
  {"arc": {"c": "A", "r": 4}, "note": "A を中心に弧をかく"},
  {"arc": {"c": "B", "r": 4}, "note": "同じ半径で B を中心に弧をかく"},
  {"meet": ["arc1", "arc2"], "name": ["P", "Q"], "note": "交点を P、Q とする"},
  {"line": ["P", "Q"], "tone": "emph", "note": "直線 PQ が垂直二等分線"}
]}
```

- `points`：名前 → `[x, y]`。名前は 1〜2 字（A、P、O、A′）。ステップ 0 はこの点だけ
- `ops`：1 つが 1 ステップ（`mode="steps"`）。種類：
  - `{"point": "C", "at": [x, y]}`、または円の上に `{"point": "P", "on": "circle1", "deg": 90}`（中心から見た角度、度）
  - `{"seg": ["A", "B"]}` 線分、`{"line": ["P", "Q"]}` 直線（両方へ延ばす）、`{"ray": ["O", "X"]}` 半直線
  - `{"circle": {"c": "O", "r": 4}}` 円（`"through": "A"` で A を通る円、`"r": ["A", "B"]` で AB の長さ）、`{"arc": {"c": "A", "r": 4}}` コンパスの弧
  - `{"meet": ["arc1", "arc2"], "name": ["P", "Q"]}` 交点。名前が 1 つなら 1 点。円と円は上の点（同じ高さなら左）が先、線と円は線の向きに先の点が先
  - `{"angle": ["A", "P", "B"]}` 角 APB の印と値（`"show"`：`both` 既定・`value`・`mark`。90° は直角の印）
  - `{"equal": [["A", "M"], ["M", "B"]], "ticks": 2}` 同じ長さの印（3 つの名前なら同じ角の印）、`{"polygon": ["A", "B", "C"]}` 塗り
- どの op にも `note`（説明の欄に足す 1 行）・`tone`（`fg`・`term`・`emph`・`accent2`・`muted`）・`id` を書ける。id を書かなければ `arc1`・`line2` のように種類ごとの番号
- 弧の範囲は、その弧で取った交点のまわり ±22°（近い交点どうしは 1 本）。交点を取らない弧は `from`・`to`（度）で範囲を書く

`mode="invariant"`：ops は初めから全部描き、`move` の点を `visit` の位置へ 1 つずつ動かす。`measure` の量を動いている間も計算して欄に出し、着いた位置の値を並べる（変わらないことを見せる）。

```json
{"points": {"O": [0, 0]}, "ops": [{"circle": {"c": "O", "r": 4}}, {"point": "A", "on": "circle1", "deg": 210}, {"point": "B", "on": "circle1", "deg": 330},
  {"point": "P", "on": "circle1", "deg": 90}, {"seg": ["P", "A"]}, {"seg": ["P", "B"]}, {"angle": ["A", "P", "B"]}],
 "move": "P", "visit": [140, 40, 160], "measure": {"angle": ["A", "P", "B"]}}
```

- `move`：動かす点。円の上の点（`on`）なら `visit` は角度（度）、ほかの点なら `[x, y]`。交点は動かせない
- `measure`：`{"angle": ["A", "P", "B"]}` 角 1 つ、または `{"sum": [["B", "A", "C"], ["C", "B", "A"], ["A", "C", "B"]]}` 角の和（三角形の内角の和）。値は整数の度。和は、各角を丸めた値の合計が丸めた和に合うように丸める
- `notes`：位置ごとの説明（省ける）

属性：`mode`（`steps` 既定・`invariant`）、`size`（点の名前と角の値の字、既定 26px）、`trail`（invariant で前の位置を薄く残す、既定 true）、`dur`（1 ステップの秒数、既定 1.2。円の上を 90° より大きく動くときは角度に比例して長く）。

交わらない円（半径が足りない）、名前の誤り、交点を動かそうとしたときは、どこを直すかを `data` で知らせる（「arc1 と arc2 が交わらない。それぞれ 3 より大きく」など）。字が重なるときは `layout`、図が入らないときは `size`。

要素の言語に従い日本語・英語で表示する。読み上げは、steps は説明を番号つきで順に、invariant は「∠APB はどの位置でも 60°」のように最後の結論。作者の `aria-label` があれば保つ。縦書きのスライドでも図は横書きで、説明の欄は図の下。

サンプルは `demo.html`（垂直二等分線、角の二等分線、円周角、三角形の内角の和）。

注意

- 点の名前は、点のまわりの 24 の向きのうち、線・円・弧・ほかの点からいちばん離れる向きに置く（同じくらいなら線のすきまの真ん中）。角の値は二等分線の上に置き、狭い角では角の中へ遠ざけ、ほかの字に重なれば二等分線の上でずらす
- 先のステップを薄く見せる表示（`ctx.preview`）：steps は先の op を最後の形で薄く、invariant は先の位置の点と線を薄く描く（値は出さない）
- 交点は計算の誤差のため、円が接するとき（中心の距離が半径の和にほぼ等しい）は 1 点になる。2 つの名前を書くと `data` で知らせる
