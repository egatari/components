子の JSON：`{"question"?, "items": [札の字 か {"label", "tone"?}]（正しい順に 2〜8 個）, "start"?: [始めの並び], "note"?: 答えと出す一言, "labels"?: {"correct"?: 正解の印の文字}}`

- `items` は正しい順に書く。始めの並びは `start`（`items` の番号、0 から）か、書かなければ 1 つずつずらした並び（どの札も正しい位置にない）
- 学習者は札をドラッグするか、Tab で札を選び Space で持ち上げ、↑ ↓ で動かし、Space で置く
- 答えはファイルに入っていて、正誤は学習者の端末で決まる。理解を確かめる問いに使い、試験には使わない

作る人向けの注（dev と確かめること）

- ステップ：0 は問いと札（作者の始めの並び）。1 で札が正しい順に動き、学習者が正しい位置に置いていた札に ✓、ほかの札の横に「あなた：3 番目」、下に「✓ 正解」か「✗ 不正解」と `note`。答えのステップでは札を動かせない
- `start` が 0〜n−1 を 1 回ずつ並べたものでないとき、正しい順と同じときは `data` で知らせ、1 つずつずらした並びにする
- 先のステップは見せない（`static preview = "none"`、manifest の `preview: "none"`）
- 学習者の状態（仕様 §8.4）：並びは、同じスライドにいるあいだはステップを進めても戻っても残る。始めの並びに戻すのは `ctx.entered` だけ。`ctx.reset` はフォーカスを外し、持ち上げた札を置くだけ
- 答えの知らせ（仕様 §8.4 `ctx.answer`）：札を動かしたあとで答えのステップに着いたとき `ctx.answer("q", 全部正しい順なら true, 値)` を 1 回呼ぶ。値は学習者の並びの上から順に `items` の番号（正しい順の番号）を `,` でつないだ字（`"2,0,1,3"` は、いちばん上に正しくは 3 番目の札を置いたということ）。部分点はない。札を動かしていなければ呼ばない。戻ってまた着けばもう 1 回。動画、印刷、`ctx.answer` の無いプレーヤーでは呼ばない。クラスに `static questions = ["q"]`
- キー：札の上で Space（と Enter）が持ち上げる・置く、持ち上げているあいだ ↑ ↓ で動かし、Esc で持ち上げた位置に戻す。動かすたびに読み上げの欄（aria-live）で「3 番目に動かしました」。札の上で使うキーはスライドに渡さない。Tab の順は画面の札の順
- 動画では操作を作らず、1 で札が正しい順に動く（印なし）。印刷は作者の並び（印なし）で、`@media print` で操作を隠す
- 縦書きのスライドでも横書きのまま。要素に入らなければ `layout` で知らせる
- 表示文は ctx.lang の日英。`labels.correct` で「✓ 正解」を変える
