子の JSON：`{"question", "answer": 正しい数, "tolerance"?: ± の幅（既定 0）, "unit"?: 単位, "note"?: 答えと出す一言, "labels"?: {"correct"?: 正解の印の文字}}`

- `answer` は数で書く（`"27"` のような字ではない）。`tolerance` までずれた答えも正解にする（`9.8` と `0.1` なら 9.7〜9.9）
- 全角の数字、`−` の負の数、小数、`1,000` の区切り、単位を付けた答えも読む。数でない答えは答えなし
- 答えはファイルに入っていて、正誤は学習者の端末で決まる。理解を確かめる問いに使い、試験には使わない

作る人向けの注（dev と確かめること）

- ステップ：0 は問いと欄（作者の状態は空の欄）。1 で正しい答え（`tolerance` があれば「（±幅）」）・学習者の数の横に「✓ 正解」か「✗ 不正解」・`note`。答えのステップでは欄を読み取り専用にする（知らせた数のまま）。戻れば直せる
- 先のステップは見せない（`static preview = "none"`、manifest の `preview: "none"`）
- 学習者の状態（仕様 §8.4）：打ち込んだ字は、同じスライドにいるあいだはステップを進めても戻っても残る。空に戻すのは `ctx.entered` だけ。`ctx.reset` はフォーカスを外すだけ
- 答えの知らせ（仕様 §8.4 `ctx.answer`）：答えのステップに数が入った状態で着いたとき `ctx.answer("q", 正解なら true, 読んだ数)` を 1 回呼ぶ。同じステップの描き直しでは呼ばない。戻ってまた着けばもう 1 回。数がない・数でないとき、動画、印刷、`ctx.answer` の無いプレーヤーでは呼ばない。クラスに `static questions = ["q"]`
- 読み方：前後の空白と `unit` の字（そのままの字だけ、前か後ろに 1 回）を除き、全角の数字・`．`・`−` `－`・`，` を半角に直し、`,` を除いて `-1.5` の形なら数。ほかの字があれば数でない（欄の下に「数で入れてください」）。正誤は |x − answer| ≤ tolerance（浮動小数の誤差に answer の 1e-9 倍を足す）
- 動画では欄を作らず空の枠を描き、1 では答えの行と `note` だけ。印刷は作者の状態（空の枠、印なし）で、`@media print` で欄を隠す。印刷の後は画面の字に戻す
- 縦書きのスライドでも横書きのまま。要素に入らなければ `layout` で知らせる
- キー：欄の中のキーはスライドに渡さない。Enter・Esc で欄を出る
- 表示文（「✓ 正解」「✗ 不正解」「答え：」「数で入れてください」）は ctx.lang の日英。`labels.correct` で「✓ 正解」を変える
