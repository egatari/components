# 足りない部品の調べ：学校の教科以外の場面（授業・研修／研究発表／ビジネス／手引き）

範囲：大学の講義（科研費の大区分 A〜K）、研修・使い方の説明、学会の口頭発表、ゼミ・進捗報告、招待講演・一般向け、ビジネス（報告・提案・ピッチ・広報）、手引き（マニュアル・規程・生活のルール）。
根拠の列は、学習指導要領の代わりに、発表・図表・文書の作法の定番の手引きを挙げた。

今の部品に小さく足せば済むもの（新しい部品にしない案）：m-curves に対数軸・帯（±σ）・2 点の差の矢印、m-quad に区画の文の型（SWOT）、m-compare におすすめの列の強調と ✓／✗、m-kpi に目標と実績の帯、m-collect に札ごとの行き先（ごみの分別）、m-menu に「今ここ」の印、m-flow に横一列の自動の配置と矢羽根の形。

新しい「伝えたいこと」の id の案：`uncertainty`（不確かさ・区間）、`distribution` は今の `spread` で足りる、`schedule`（予定の帯）、`decision`（判断の分かれ道）、`matrix`（2 つの分類の対応）、`flow`（量の流れ。FT の Flow に当たる）、`algorithm-trace`（手順の状態の変化）、`warning`、`checklist`、`lookup`、`canvas`。予約の `deviation` は `m-diverge`／`m-waterfall` で埋まる。
